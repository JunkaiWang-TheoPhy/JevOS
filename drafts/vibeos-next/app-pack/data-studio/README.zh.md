# Data Studio 独立新稿样例包

这是预制验收／演示样例，不是现场模型生成。首次打开的实验组、对照组数据都是示例；CSV 导入、单元格编辑、统计与 SVG 绘图由本地程序执行。

## 交付接口

- `app.mjs` 命名导出 `dataStudioDraft`，ID 为 `draft-data-studio`。
- `app.d.mts` 将该导出声明为现有 `GeneratedAppPackage`。
- HTML 是 body fragment；CSS 独立；JS 是普通脚本，以 async IIFE 初始化。
- 只使用 `vibe.getState()` 和 `vibe.setState(patch)`。宿主为每个实例决定状态作用域。
- `model.mjs` 中 `createDataModel` 的函数体原样内联进应用脚本，因此测试与界面使用同一份解析和绘图逻辑。
- 本任务未修改注册表。仅供隔离的新稿集成，不自动加入旧版。

## 操作

点击“导入 CSV”，粘贴 CSV 或选择本地文件，再点击“导入数据”。第一行作为列名，其余行参与分析。单元格可以直接编辑，统计与图表即时更新；“数值列”选择要分析的列，可切换折线和柱状图。重置按钮恢复明确标注的示例数据。

导入会替换当前表格。无效或超限导入保留旧数据并显示错误。保存采用串行写入并合并等待中的最新快照，避免较早的写入覆盖新编辑。关闭前可观察底部“已保存”状态。

## 数据边界

- 最多 200 行，包含表头；最多 20 列。短行补空字符串，不补造数值。
- CSV 支持 UTF-8 BOM、CRLF、引号中的逗号与换行，以及双引号转义；不支持 Excel 公式、分号／制表符分隔或编码自动检测。
- 输入／文件最大 128 KiB；实际保存状态最大 **30 KiB**，为宿主的 32 KiB 上限预留空间。单个单元格最多 2048 字符。
- 支持有限十进制、负数和科学计数法，数值绝对值不超过 `1e12`。
- 空值、非数字与超范围值不当作零；跳过数量在图表下方显示。折线在缺失值处断开。
- 全等值会扩展显示范围；零柱的高度为零。数据按输入行序展示，不擅自排序。
- 图表横轴使用第一列作为标签；分析第一列时以数据行序号作标签。
- 用户文本只进入 input value、textContent 或 SVG text 节点，不拼接为 HTML。
- 没有网络、系统 shell、持续动画或后台轮询。
